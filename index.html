SOBRE O PROJETO

Informação de forma simples e organizada.

O Loterias-Caixas é um projeto demonstrativo desenvolvido para fins educacionais e de portfólio, com o objetivo de apresentar consultas de resultados de diferentes modalidades de loteria por meio de tecnologias web.

As informações são obtidas por meio de uma API externa e dependem da disponibilidade do serviço consultado.

🍀 LOTERIAS-CAIXAS

Projeto independente, sem vínculo oficial com a Caixa Econômica Federal.
