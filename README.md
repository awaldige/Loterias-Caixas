# 🎲 Loterias-Caixas

Aplicação web demonstrativa para consulta de resultados de diferentes modalidades de loteria, com interface moderna, responsiva e organizada.

O projeto foi desenvolvido como estudo de tecnologias web e faz parte do portfólio de desenvolvimento da **AW TECHNOLOGY**.

## 🚀 Funcionalidades

- 🎯 Interface organizada em cards para 10 modalidades de loteria.
- 🔎 Consulta de resultados por número do concurso.
- 📅 Consulta do último resultado disponível.
- 🔢 Exibição dos números sorteados e informações específicas de cada modalidade.
- 🍀 Exibição de trevos da sorte na +Milionária.
- ⚽ Exibição dos jogos e resultados da Loteca.
- ❤️ Exibição do time do coração na Timemania.
- 📆 Exibição do mês da sorte no Dia de Sorte.
- 🌗 Alternância entre temas claro e escuro.
- 💾 Persistência da preferência de tema e do último concurso consultado no navegador.
- ⚠️ Tratamento de erros e mensagens para indisponibilidade do serviço externo.
- 📱 Layout responsivo para computadores, tablets e celulares.

## 🎰 Modalidades disponíveis

- Mega-Sena
- Lotofácil
- Quina
- Lotomania
- Dupla Sena
- Timemania
- Dia de Sorte
- Loteca
- +Milionária
- Super Sete

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura semântica da aplicação.
- **CSS3** — identidade visual, responsividade, Grid e Flexbox.
- **JavaScript (ES6+)** — manipulação do DOM, consumo de API e funcionalidades interativas.
- **Fetch API** — requisições assíncronas para consulta dos resultados.
- **LocalStorage** — armazenamento de preferências e informações no navegador.
- **Vercel** — hospedagem da aplicação.

## ▶️ Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/awaldige/Loterias-Caixas.git
```

2. Entre na pasta do projeto:

```bash
cd Loterias-Caixas
```

3. Abra a pasta no Visual Studio Code.

4. Execute o projeto utilizando a extensão Live Server ou outro servidor HTTP local.

Não é necessário instalar dependências ou configurar um backend próprio.

## 📌 Observações importantes

Este é um **projeto demonstrativo**, desenvolvido para fins educacionais e de portfólio.

As consultas dependem de um serviço externo de resultados, que pode apresentar instabilidades, indisponibilidade ou alterações. Por isso, nem todos os concursos estarão necessariamente disponíveis em todos os momentos.

O projeto é independente e não possui vínculo oficial com a Caixa Econômica Federal.
